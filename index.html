02 · Migration map

What to replace, and with what

NIST published the first post-quantum standards in August 2024. Symmetric crypto and SHA-2 survive; public-key crypto has to move.

03 · The clock

Harvest now, decrypt later

Attackers can record encrypted traffic today and decrypt it once quantum computers are strong enough. Data with a long shelf life is already exposed.

2024

Standards published

NIST releases FIPS 203 (ML-KEM), 204 (ML-DSA) and 205 (SLH-DSA).

04 · How it works

Three passes, one screen

PASS 01

Quantum exposure

RSA, elliptic curves, Diffie-Hellman, DSA and SSH keys, by API call, cipher suite, curve name and JWT algorithm.

PASS 02

Classical mistakes

MD5, SHA-1, RC4, 3DES, ECB, small keys, TLS 1.0/1.1 and private keys committed to source.

PASS 03

AI-agent configs

Auto-approved tools, wildcard permissions, unpinned MCP servers, hard-coded secrets, hidden instructions and invisible Unicode.

Pattern-based and line-by-line: it can miss crypto hidden behind wrappers and can flag harmless mentions. A clean result is a starting point, not proof a system is quantum-safe. Add pqc-radar: ignore to a reviewed line to suppress it.
